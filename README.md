# carta-kari 🌼

Una carta digital por el Día de las Flores Amarillas.
21 de septiembre de 2026 · 28.03.2025 — ∞

Todo vive en un solo archivo `index.html`: sin imágenes, sin audio y sin
dependencias que haya que instalar. Se abre con doble clic o desde
GitHub Pages.

## Créditos

La animación de las flores amarillas está basada en el proyecto
[floresamarillas](https://github.com/kevinvargasx) de Kevin Vargas
([@kvargasdev](https://www.tiktok.com/@kvargasdev)). El CSS original de la
escena se conservó tal cual; la carta, la máquina de escribir y el resto
del diseño son añadidos.
